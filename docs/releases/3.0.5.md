# Music Together Android 3.0.5

## 房间分享

- 房间右上角菜单新增“分享房间”，可以生成包含当前歌曲、封面、房间名称、在线人数和二维码的分享图片。
- 分享弹窗支持预览分享卡片、调用 Android 系统分享，以及单独复制房间链接。
- 分享图片通过应用缓存和 FileProvider 安全导出，不需要申请公共存储权限；关闭弹窗或退出页面时会取消尚未完成的生成任务。
- 当前歌曲没有封面、二维码生成失败或封面网络请求失败时保留可用的降级样式，不影响复制和分享房间链接。

## 分享链接与应用唤起

- 新的房间邀请链接使用当前房间所属服务端的 `/join?ROMMid=<房间号>` 地址，不再强制经过官方服务端域名。
- 打开分享链接后，服务端网页可以通过 `musictogether://join` URL Scheme 唤起 Android 应用，并自动连接链接对应的服务端和加入房间。
- 支持 HTTP、HTTPS、自定义端口和反向代理基础路径，第三方部署生成的邀请链接会继续连接其自身服务端。
- 应用冷启动和已在后台运行时都可以接收房间链接；收到新链接后复用现有服务器切换、房间密码和加入流程。
- 保留对旧版网页 `/room/<房间号>`、`musictogether://room`、`musictogether://join`、`intent://` 以及旧 `room`/`server` 参数的兼容。

## 稳定性与兼容性

- 为分享链接构造、URL Scheme、浏览器 Intent、第三方服务端、反向代理路径和旧链接格式补充单元测试。
- 分享卡片内容与布局计算拆分为独立模块，并补充长标题、缺少封面、歌手信息和在线人数等场景测试。
- 更新 Android Manifest、分享文件路径和项目架构文档，记录外部链接处理与分享资源生命周期。
- 版本号更新为 `3.0.5`，`versionCode` 更新为 `29`。
