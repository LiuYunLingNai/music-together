# Music Together Android 3.0.6

## 房间分享修复

- 修复点击“分享图片”时应用直接崩溃闪退的问题。
- 调整分享图片的 URI 数据构造方式，避免部分 Android 系统和定制系统在读取分享图片类型时触发空指针异常。
- 系统分享面板和目标应用现在都会获得分享图片的临时读取权限，提高 Android 12 及以上版本和部分定制系统的兼容性。
- 系统缺少可用分享组件、拒绝图片 URI 权限或分享面板异常时不再退出应用，并自动复制房间链接作为降级方案。
- 分享启动失败时写入客户端调试日志，方便继续定位特定设备或分享应用的兼容问题。

## 发布信息

- App 内置默认服务地址切换为 `https://sharemusic.kuro.ltd`，新的 HTTPS 房间链接可直接唤起应用。
- 版本号更新为 `3.0.6`，`versionCode` 更新为 `30`。
