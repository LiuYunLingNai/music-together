# Music Together Android 3.0.1

## 大厅与导航

- 大厅改为更聚焦的分区首页，提供首页、搜索、媒体库、推荐和设置五个入口；加入房间后可在底部导航直接回到推荐内容。
- 首页恢复“添加服务器”和“管理服务器”入口，顶部快捷按钮与首页操作均可进入连接设置，方便首次连接、切换或维护服务器。
- 创建房间与加入房间分离为清晰的独立操作；加入房间使用单独弹窗，支持输入房间号或邀请链接。
- 重新整理迷你播放器、底部导航和系统状态栏的安全边距，避免返回按钮、状态栏和底部控件重叠；横竖屏布局保持一致可用。
- 首页卡片、导航与内容区域加入克制的半透明玻璃效果，在保留信息层级和文字可读性的同时改善整体视觉连贯性。

## 搜索与推荐

- 未连接当前服务器时，搜索页仅显示连接提示和入口，不再展示无法使用的搜索框；连接成功后即可按已接入音乐源搜索歌曲。
- 加入房间后，主页新增推荐页，聚合当前已登录音乐平台返回的推荐歌曲和歌单，无需逐个平台切换浏览。
- 推荐歌曲支持直接加入播放队列、置顶到当前歌曲后方，以及打开来源歌单继续浏览。
- QQ 音乐推荐支持继续加载后续推荐内容；加载过程与其他推荐来源一起去重合并。
- 推荐歌单改为自适应网格：封面尺寸更紧凑，横屏会根据可用宽度自动调整列数，填满整行，不再出现右侧大块留白。
- 推荐歌曲和歌单封面复用统一的平台来源角标，便于快速判断内容来自 QQ 音乐、酷狗、B 站等平台。

## 播放体验

- 新增“允许与其他应用同时播放”设置，默认关闭以保持原有播放行为。
- 开启后，应用不再申请 Android 音频焦点，可与导航、短视频等其他应用的媒体声音同时播放；关闭后继续沿用原有的独占播放和系统音频焦点处理。

## 本地媒体库

- 媒体库页面适配新的大厅导航和安全区域，继续提供已下载歌曲的浏览与本地播放入口。
