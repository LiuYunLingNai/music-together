# Music Together Android 3.0.3

## 双风格界面

- 新增 Material 3 与 MIUIX 两套原生 Compose 界面，可在“设置 → 外观与主题”中随时切换，切换过程不会断开服务器、退出房间或中断播放。
- 新增跟随系统、浅色和深色主题模式；Android 12 及以上设备可使用系统动态配色。
- MIUIX 深色模式新增纯黑背景选项，并统一页面、顶栏、弹层和底部区域的背景衔接，减少局部黑块和颜色割裂。
- 为 MIUIX 控件补齐 Material 组件的颜色映射与公共弹层适配，改善混合页面中的文字对比度、菜单和底部弹窗表现。

## 设置与个性化

- 重构设置导航，将账号与安全、服务器连接、外观与主题、播放器、播放与同步、存储与更新、应用更新、服务器管理和通用选项拆分为独立二级页面。
- 进入设置二级页面后自动隐藏底部导航，系统返回键和返回手势会优先返回设置首页。
- 新增应用模糊、底栏样式和玻璃效果设置；Material 3 保持标准导航，MIUIX 可选择标准底栏或悬浮底栏。
- 扩展播放器显示设置，可分别调整翻译、音译、歌词字号、字重、竖屏焦点位置、弹簧与缩放动画、非当前行模糊、动态背景及其运动强度。
- 非当前歌词行模糊默认关闭，用户可按设备性能和视觉偏好自行开启。

## 悬浮底栏与迷你播放器

- MIUIX 新增液态玻璃悬浮底栏，支持实时背景采样、模糊、折射、色散、设备倾斜高光、阻尼拖动和橡皮筋反馈。
- 优化底栏的系统导航栏避让、从右到左布局和无障碍语义，并为不支持实时光学效果或关闭玻璃效果的设备提供实色胶囊样式。
- 有歌曲播放时，迷你播放器与导航胶囊在同一行自适应分配空间；迷你播放器改为紧凑布局，保留封面、曲目信息和必要播放操作。
- 修复悬浮底栏选中指示器尺寸可能超出标签区域的问题，并消除主页底部多余黑色占位和内容遮挡。

## 播放器与弹层

- 统一播放器按钮、滑块、菜单和表面组件，使横竖屏播放器能随当前界面风格显示一致的控件。
- 优化播放器背景、歌词和控制区域的层次与模糊效果，保持歌词时间轴和房间同步逻辑不变。
- 房间与音质、音源账号与歌单等播放器弹层改为风格感知实现；弹层内存在详情页时，返回键、返回手势和遮罩点击会先返回上一级。
- 修复 MIUIX 窗口弹层内下拉选项的兼容问题，并增加 Material 3 与 MIUIX 弹窗展开路径测试。

## 构建与兼容性

- 升级至 Kotlin 2.4.10、Gradle 9.5.0、Android Gradle Plugin 9.3.1、Compose 2026.06.01 与 MIUIX 0.9.3。
- `compileSdk` 升级至 Android 37，应用的 `targetSdk` 仍保持 Android 36，最低支持 Android 8.0。
- CI 构建环境升级至 JDK 21，修复新版构建链生成的类文件无法在 JDK 17 测试进程中加载、导致 `UnsupportedClassVersionError` 的问题。
- 增加界面风格持久化、背景配色、悬浮底栏尺寸、设置导航布局和弹层兼容性测试。
