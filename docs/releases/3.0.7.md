# Music Together Android 3.0.7

## 自定义分享卡片

- 分享卡片背景新增四种来源：动态渐变、歌曲封面、本地图片和网络图片，可在“设置 → 外观与主题 → 分享卡片”中切换。
- 支持调节背景模糊与背景暗化强度，并可分别控制歌曲封面、入房二维码和房间链接是否显示。
- 分享卡片设置会持久化保存；选择本地图片时会带上临时读取权限，避免部分系统读取失败。

## 歌词加载与匹配

- 歌词改为并行加载 TTML 与平台歌词，解析移出主线程，减少切歌时的卡顿和等待。
- 新增按服务器隔离的有界歌词缓存，并提前预取下一曲歌词，连续播放时切歌更快。
- 协程取消现在会真正中断底层网络请求，并细分请求超时，退出房间或快速切歌不再遗留无效请求。
- 接入多歌词源择优：按正文完整度、副歌覆盖、逐字时间轴和对唱结构评估歌词质量，自动选中更合适的一版。
- 译文与音译会与选中的主歌词对齐，并保持 AMLL 时间轴不被改写；补源请求有超时限制，旧服务端缺少相关字段时自动回退。

## 单一 MIUIX 界面

- 界面统一为 MIUIX 原生 Compose 视觉体系，移除 Material 3 界面风格及其在“设置 → 外观与主题”中的风格切换入口。
- 删除各页面中按风格分支渲染的 Material 3 实现，房间、大厅、平台账号、搜索结果、播放器弹层和设置页现在只有一套 MIUIX 呈现。
- 原有界面设置全部保留：主题模式、纯黑背景、界面模糊、底栏样式与液态玻璃效果不再依附风格切换，可直接使用。
- Material 组件仍作为内部排版与图文原语参与渲染，其配色和字体继续映射 MIUIX 色板，页面视觉不会出现对比度回退。

## 外观

- 系统动态色改为默认关闭，界面默认使用 MIUIX 标准色板，避免壁纸主色导致界面配色不可预期。
- 仍需系统动态配色的用户可在“设置 → 外观与主题”中手动开启。

## 发布信息

- 版本号更新为 `3.0.7`，`versionCode` 更新为 `31`。
- 最低支持 Android 8.0，`targetSdk` 保持 Android 36。
