# Music Together Android 3.2.1

## 舞台设置修复

- 修复雾笺参数保存后画面仍使用默认值的问题，恢复上游舞台入口的参数与字号适配。
- 修复雾笺共用背景、部分背景静态模式和莫奈关键词开关不生效的问题。
- 静止舞台改用共享字幕，字幕行数、音译、底板和不透明度设置可以正常生效。
- 按舞台的实际支持范围禁用不适用的选项，并说明原因；凝彩依赖智能拍点的景深控制暂不可用，普通镜头控制保持可调。

## 上传与界面兼容

- 文件上传统一使用系统文档选择器，修复旧 WebView 图片选择后没有回传文件的问题，保留多选。
- 修复部分 WebView 将竖屏配置面板显示为侧栏的问题，现在按实际视口宽高布局。
- 为不支持 color-mix 的旧 WebView 补充深色设置令牌和滑条轨道颜色回退。
- 选择内置字体风格时正确退出自定义字体，修复切换后字体风格没有变化的问题。

## 安装包

- Standard APK、vivo/iQOO APK 和 Standard AAB，以及各产物 SHA-256 校验文件。
- `versionCode` 为 `35`，最低支持 Android 8.0，目标版本保持 Android 16。
