# Music Together Android 3.0.4

## 房间成员与权限

- 适配网页端的多设备成员信息，成员列表会展示当前在线设备或浏览器，以及离线成员最近使用的客户端。
- 同一账号连接多个设备时按设备逐行展示，设备名称和浏览器名称支持完整换行，不再因为单行省略导致无法分辨具体设备。
- 为设备类型补充手机、电脑和浏览器图标；服务端缺少客户端信息时继续安全回退，不影响成员列表显示。
- 房主和服务器管理员可以直接在成员列表中将普通成员切换为房间管理员，或取消其房间管理员身份。
- 成员角色操作改为紧凑的管理员开关，不能修改本人、房主或服务器管理员，最终权限仍由服务端校验。
- 移除角色选择的窗口级二级弹窗，修复横屏打开成员权限操作时出现黑色窗口的问题。
- 成员列表继续显示头像、在线状态、当前身份和“你”标识，长设备信息不会再挤压或遮挡成员资料。

## 搜索与点歌

- 搜索结果中的歌曲名、歌手和专辑支持多行完整展示，减少长标题被截断后无法判断歌曲的问题。
- 搜索结果的添加、下载和置顶操作收进“更多”菜单，释放歌曲信息展示空间并保持列表整洁。
- 搜索结果中的下载状态和下载进度继续在菜单内实时反馈，已下载歌曲会显示完成状态。

## 私人漫游推荐

- 房间设置新增“私人漫游”，房主可以在队列没有后续歌曲时启用基于个人平台账号的推荐。
- 支持网易云音乐、QQ 音乐、酷狗音乐和酷狗概念版作为漫游音源。
- 网易云音乐支持默认、熟悉、探索、运动、专注、深夜和 AI DJ 模式；其他平台使用默认模式。
- Material 3 和 MIUIX 两套房间设置界面均提供漫游开关、音源和模式选择。
- 兼容旧版服务端，未返回漫游字段时默认关闭，不影响原有房间播放和推荐功能。

## 稳定性与兼容性

- 补充房间漫游设置的 JSON 解析和旧服务端回退测试。
- 更新项目架构文档，记录成员设备信息、角色管理和私人漫游协议行为。
- 版本号更新为 `3.0.4`，Standard Debug 构建验证通过。
