## 服务端兼容核对结论

- 队列确认已有 `source:sourceId` / B 站 `urlId` 身份，不依赖服务端可能重新分配的队列 ID；下一首现携带当前 `trackId`，服务端可拒绝晚到请求。
- 新增可选播放 `revision` 与同步响应 `trackId` 的检查；旧服缺字段时保留兼容。暂停/Seek 在缓冲期间覆盖待加载意图。
- 新版访客只存在于在线 `users`，客户端显示时合并持久名册，不再把访客离线后留在列表。
- 下载前解析播放地址携带当前 `roomId`，由服务端按房间资格选择认证与音质；Android 不上传平台 Cookie 到第三方媒体域名。
- 会员子请求失败保留等级、扫码查询瞬时失败重试、退出/撤销后的授权版本校验和平台凭证续期均由 main 服务端实现，不复制进 Kotlin。Android 保留原有 QQ `reauth_required` 才删除本机凭据的策略，并对新增偏好请求隔离服务器、房间和身份。
- 自动混音及浏览器音效、渲染、缓存代码不属于本批兼容移植范围。
